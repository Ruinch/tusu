## 🎯 1. Задача и Проблема

Каждый год миллионы абитуриентов сталкиваются с когнитивной перегрузкой при поступлении:
- Десятки разрозненных сайтов университетов и посольств.
- Общие списки «Топ-100 вузов», не учитывающие реальный семейный бюджет, школьный GPA и уровень сданных тестов.
- Риск упустить критические дедлайны на 100% гранты и стипендии (DAAD, DSU в Италии, стипендии KAIST, гранты МОН РК).
- **Главная боль:** абитуриент и его родители не понимают, за что браться прямо сейчас и каков следующий шаг.

### Решение TUSU.AI
Интеллектуальный веб-сервис с чистым, сдержанным интерфейсом и прозрачной аналитикой (без едких градиентов и дешевого «AI-шума»), который за 3 минуты превращает академический профиль ученика в понятный маршрут поступления: **куда поступать, почему этот вариант подходит, каковы реальные шансы на грант и какое действие сделать следующим**. Название происходит от казахского слова *«Түсу»* (поступать в университет).

## 🧭 2. Полный сквозной путь пользователя (7 обязательных этапов)

Сервис реализует один непрерывный, логичный и адаптивный сценарий:

| Этап | Название | Что получает абитуриент / эксперт |
|:---|:---|:---|
| **Этап 1** | **Вход (Onboarding)** | Четкое объяснение ценности, сравнение «как сейчас» vs «как с AI», быстрый старт через пресеты жюри в 1 клик. |
| **Этап 2** | **Профиль (Анкета)** | Класс/возраст, направления (CS & AI, Инженерия, Бизнес и др.), GPA, баллы тестов (IELTS, SAT, ЕНТ), олимпиады, бюджет ($0 грант, $5k, $15k, $30k+) и целевые страны. |
| **Этап 3** | **Диагностика** | Комплексный AI-аудит: резюме портрета, 3-4 ключевые сильные стороны, узкие места и дефициты тестов, сформированная образовательная цель и % готовности. |
| **Этап 4** | **Рекомендации** | Классификация программ на **🌟 Dream**, **🎯 Target**, **🛡️ Safety**, персональное обоснование («почему подходит именно вам»), шансы на грант и проверенные источники. |
| **Этап 5** | **Сравнение** | Интерактивная матрица сопоставления минимум 2 вариантов по стоимости, стипендиям, дедлайнам, расходам на жизнь и AI-вердикт. |
| **Этап 6** | **Roadmap** | Поквартальная временная шкала (Q1–Q4): экзамены, документы, мотивационные письма, конкурсы грантов с возможностью фильтрации и отметки прогресса. |
| **Этап 7** | **Следующее действие** | **Один выделенный фокус-шаг №1** с дедлайном и тактическим руководством, кнопкой «Отметить выполненным ✓» и праздничным конфетти-вознаграждением. |

## 🚀 3. Киллер-фичи для жюри

1. **Мгновенная реактивность (Reactivity Engine):** Изменение любого поля в анкете (например, смена бюджета на «100% грант» или повышение IELTS до 7.5) мгновенно пересчитывает матчинг, шансы, диагностику и расписание дорожной карты.
2. **Демо-режим для жюри в 1 клик:**
   - 👨‍🎓 *Алихан (11 класс)*: GPA 4.85, SAT 1440, IELTS 7.5, олимпиадник. Цель: Топ-вузы мира (NU, KAIST, TUM) на 100% грант.
   - 👩‍💻 *Диана (11 класс)*: GPA 4.25, ЕНТ 118, IELTS 6.0. Цель: IT-программы Казахстана (AITU, КБТУ, КазНУ) по гранту МОН РК.
   - 🚀 *Тимур (10 класс)*: GPA 4.4, ранняя подготовка в Европу с нулевым бюджетом (стипендия DSU в Италии).
3. **Экспорт дедлайнов в календарь (`.ics`):** Загрузка персонального расписания в Apple Calendar, Google Calendar или Outlook в 1 клик.
4. **AI-советник по мотивационному эссе (SOP Advisor):** 4-частный фреймворк эссе с генерацией смысловых блоков под конкретный выбранный университет.

## 🧪 4. Проверочный сценарий для экспертов жюри

1. **Шаг 1 (Вход):** Нажмите кнопку *«Тест для жюри: Профиль Алихана (1 клик)»* в правом верхнем углу или на главном экране.
2. **Шаг 2 (Диагностика):** Оцените объективность сформированных сильных сторон (олимпиады, высокий SAT) и выявление дефицитов.
3. **Шаг 3 (Рекомендации):** Перейдите на этап 4 и проверьте блок *«Почему подходит именно вам»* у Nazarbayev University и KAIST.
4. **Шаг 4 (Проверка реактивности):**
   - Нажмите *«Редактировать анкету»* (Этап 2).
   - Смените бюджет с *«100% Грант»* на *$30,000+* и добавьте страну *США*.
   - Вернитесь в рекомендации — в топе появится *Georgia Tech* и изменится стратегия в диагностике!
5. **Шаг 5 (Сравнение):** Отметьте 2 вуза галочками «Добавить к сравнению» и перейдите на этап 5 для детальной матрицы.
6. **Шаг 6 (Следующее действие):** Перейдите на этап 7, нажмите *«Отметить выполненным ✓»* и убедитесь, что прогресс плана увеличился, а на первый план выдвинулась следующая приоритетная задача.

## 💻 5. Технический стек и архитектура

- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS v4.
- **Icons & UI-kit:** Lucide React, Canvas-Confetti, Tailwind Color Tokens (Dark Slate/Indigo/Cyan).
- **Recommendation & Scoring Engine:** Модульный гибридный движок (`src/utils/recommendationEngine.ts`):
  - Многофакторный взвешенный скоринг соответствия профиля:
    $$\text{Score} = f(\text{FieldMatch}, \text{CountryPreference}, \text{GPA}, \text{IELTS}, \text{SAT}, \text{ENT}, \text{FinancialFit}, \text{Olympiads})$$
  - Автоматическая классификация на Dream / Target / Safety.
  - Генерация аргументации на естественном человеческом языке без галлюцинаций.
- **Roadmap Generator:** Динамический генератор этапов (`src/utils/roadmapGenerator.ts`), привязанный к дедлайнам учебного года.
- **Хранение данных:** LocalStorage Persistence — состояние не теряется при перезагрузке страницы.

## 🛠️ 6. Инструкция по локальному запуску

Требования: Node.js 18+ и npm.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/norerade/tusu-ai
cd tusu-ai

# 2. Установить зависимости
npm install

# 3. Запустить режим разработки
npm run dev

# Сервис запустится по адресу: http://localhost:5173
```

Сборка для продакшена:
```bash
npm run build
npm run preview
```

## ⚖️ 9. Ограничения решения

- Сервис фокусируется на этапе выбора стратегии, программ и подготовки документов и не заменяет собой государственные порталы подачи (egov, Universitaly, Common App).
- Скоринг вероятности поступления носит индикативно-диагностический характер и стимулирует абитуриента закрывать пробелы в тестах до дедлайнов.

## Chach: Anthropic API

Для локальной разработки создайте файл `.env.local` в корне проекта:

```env
ANTHROPIC_API_KEY=ваш_ключ_anthropic
```

Команда `npm run dev` поднимает server-side endpoint `/api/chach`. Ключ не передаётся в браузер. Для production перенесите обработчик из `vite.config.ts` в серверную или serverless-функцию вашего хостинга и сохраните `ANTHROPIC_API_KEY` в его secrets.

Регистрация, тесты и профиль текущего MVP сохраняются локально в браузере. Загружаемые файлы используются как список приложений к CV; сами файлы на сервер не отправляются.
